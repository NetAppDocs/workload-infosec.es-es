= Métricas y telemetría para NetApp Workload Factory
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Workload Factory recopila y almacena métricas a nivel de volumen y de sistema de archivos en AWS CloudWatch para darte visibilidad operativa sobre el rendimiento y la capacidad del almacenamiento. Las métricas calculadas, como el rendimiento, se derivan de estos valores recopilados. Conoce las definiciones de las métricas, la frecuencia de recopilación, el comportamiento de actualización y los detalles de retención.



[[metrics-included]]
== Métricas incluidas

NetApp Workload Factory utiliza estas métricas para los registros operativos y eventos:

* Métricas de CloudWatch a nivel de volumen (recopiladas por volumen)
* Métricas a nivel del sistema de archivos de CloudWatch (recogidas por sistema de archivos)
* Métricas calculadas
* Calendario de recogida y retención




[[about-operational-metrics]]
== Acerca de las métricas operativas

Las métricas calculadas utilizan esta fórmula:

* Rendimiento (bytes/segundo) = (NetworkSentBytes + NetworkReceivedBytes) / periodo


Comportamiento de actualización:

* Las métricas de volumen y clúster se actualizan cada 12 horas.
* Las métricas de latencia se actualizan cada 20 minutos.
* Los elementos de DynamoDB caducan automáticamente después de 14 días.




[[about-telemetry-data-collection]]
== Acerca de la recopilación de datos de telemetría

* OpenTelemetry trazas exportadas a través de OTLP HTTP a SigNoz (observabilidad interna)
* Medición del uso de la IA (recuento de tokens, costes de los modelos) almacenada en AWS Timestream
* NetApp Console registros de auditoría (nombre de la acción, estado, metadatos de la solicitud/respuesta, marcas de tiempo)




[[volume-level-cloudwatch-metrics-collected-per-volume]]
== Métricas de CloudWatch a nivel de volumen (recopiladas por volumen)

[cols="2,2,1,3"]
|===
| Métrica | Nombre de AWS CloudWatch | Unidad | Qué mide 


| Capacidad de almacenamiento de volumen | StorageCapacity | Bytes | Capacidad total asignada 


| Espacio de almacenamiento utilizado | StorageUsed | Bytes | Datos reales almacenados 


| Bytes de datos leídos | DataReadBytes | Bytes | Rendimiento de lectura 


| Bytes de datos escritos | DataWriteBytes | Bytes | Rendimiento de escritura 


| Operaciones de lectura de datos | DataReadOperations | Recuento | IOPS de lectura 


| Operaciones de escritura de datos | DataWriteOperations | Recuento | IOPS de escritura 


| Operaciones con metadatos | MetadataOperations | Recuento | IOPS de metadatos 


| Tiempo de la operación de lectura de datos | DataReadOperationTime | Segundos | Latencia de lectura 


| Tiempo de la operación de escritura de datos | DataWriteOperationTime | Segundos | Latencia de escritura 


| Tiempo de operación de metadatos | MetadataOperationTime | Segundos | Latencia de metadatos 
|===

| Pool de capacidad utilizada | StorageUsed (pool de capacidad) | Bytes | Consumo del capacity pool

| Uso del rendimiento de red | NetworkThroughputUtilization | Porcentaje | Porcentaje de utilización de la red

| Red recibida | NetworkReceivedBytes | Bytes | Red de entrada

|===
